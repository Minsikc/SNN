# 4. Half-select sequence disturbance

A cell sitting at the intersection of a driven row and an undriven column (or
vice versa) is *half-selected*. Single half-selects are harmless. **Ordered
pairs applied back-to-back are not.**

## Run order

```
python half_select_seq16.py         # 16 ordered pairs, HS_SEQ opcode
python seq_attractor_map.py         # 5 starting states x cycle sweep to 300
python plot_seq_attractor.py

python halfselect_seq_in_update.py  # how often a REAL update fires each pair
python plot_halfselect_seq_in_update.py
python plot_halfselect_heatmaps.py
```

`HS_SEQ` command format — the pair is encoded as tens digit (first line) plus
units digit (second):

```
F,<pair>,5,HS_SEQ,N56,1,<cycles>,99999,F,15,100,100,10,20,0,10
```

`read_period` (99999) is deliberately larger than the cycle count so the
exposure carries no reads.

## Result: 8 of 16 pairs move charge

Classified by whether five different starting states (full pot / mid pot /
reset / mid dep / full dep) collapse to one level by 300 cycles:

| group | pairs | attractor |
|-------|-------|-----------|
| potentiating | N2+N1, N1+N2 | +473, +457 LSB |
| reset-like | N4+N2, N3+N1, N1+N3, N2+N4 | +21 … +27 LSB |
| depressing | N3+N4, N4+N3 | −417, −428 LSB |
| inert | N1+N1, N2+N2, N3+N3, N4+N4, N1+N4, N4+N1, N2+N3, N3+N2 | no convergence |

An alternating pair reproduces nearly the full select strength; applying the
same two lines *block-wise* instead is 20–95× weaker.

## What a real update actually fires

The update logs only aggregate exposures (`H_N1..H_N4`), which cannot tell
`N1→N2` from `N2→N1`. The ordering lives in the bit streams, so those are
regenerated by replaying the same seeded RNG (verified against the stored
`u,v` every trial).

Two things decide which pair a cell sees, and both come from the firmware:

1. **Slot order is `clear → set row → set col → clear col → clear row`.** The
   row line falls last, so the transistor left on at the end of a slot is the
   ROW line whenever the row bit is 1 — *including on a coincidence slot*.
2. **State persists across the four quadrant commands** of one trial. A cell
   left on N1 by the potentiation command and then driven by N4 sees `N1+N4`.

Getting either wrong undercounts badly — an earlier version that treated
coincidences as chain-breaking and reset state per quadrant found 0.74 pairs
per cell-update; the correct count is **3.76**, of which **47% span two
quadrant commands**.

| pair | attractor | POT-asked cells | DEP-asked cells |
|------|-----------|-----------------|-----------------|
| N2+N1 / N1+N2 | +473 / +457 | 1.24 / 1.25 | 0.46 / 0.43 |
| N4+N3 / N3+N4 | −428 / −417 | 0.51 / 0.38 | 1.23 / 1.23 |
| N1+N3 / N2+N4 | +23 / +21 | 0.28 / 0.21 | 0.32 / 0.15 |

The reset-group pairs occur **only** at a sign change, and every one of those
occurrences is cross-quadrant.

## Effect size

Regressing the measured delta on the desired update and the three exposure
groups (regressor cross-correlation |r| ≤ 0.4, so they are separable):

```
delta = 12.41·desired + 1.65·(POT pairs) − 1.60·(reset) − 1.79·(DEP pairs)
r 0.9783 -> 0.9807,  residual 9.48 -> 8.96 LSB
```

**≈1.7 LSB per pair = 13% of one coincidence** (13.0 LSB). With a net drive of
1.6 pairs per cell, the total is ~2.7 LSB, i.e. it raises the effective gain by
about 6%.

Cells are **not** only pushed toward the direction they were asked to move — a
POT-asked cell still receives 0.89 depressing pairs per update. But the *net*
drive does follow the request (POT +1.60, DEP −1.57, zero +0.07), so the term
amplifies rather than corrupts.

The `act_reset` coefficient (−1.60) should not be read as physics: the reset
group's attractor is state-dependent (pulls down from above, up from below)
and a single linear coefficient cannot express that.

## Cautions

- **A single trial's 25 cells are far too few to read a trend.** Per-trial
  correlation between residual and net drive has sd 0.30 and is negative in
  7 of 40 trials, while the mean is +0.32 (6.7σ from zero). Heatmaps of one
  trial are illustrations, not evidence.
- The first version of this measurement reported "−45 LSB per N4 pulse,
  additive" — entirely an artifact of `STOCHASTIC_*` performing 2 reads per
  call (80 reads over 20 cycles) while the control performed none.
